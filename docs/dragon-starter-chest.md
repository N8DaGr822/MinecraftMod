# Dragon Starter Chest

An optional equipment kit for preparing to fight the vanilla Ender Dragon. Find **Dragon Starter Chest** in Creative's Functional Blocks tab, or use:

```mcfunction
/give @s darkspawn:dragon_starter_chest
```

Place it like a normal chest, then open it and take the supplies. Sneak while placing against an interactive block. Placement consumes one kit in Survival; Creative retains it as usual. There is no survival crafting recipe or automatic world placement.

The placed block is a normal chest. Breaking it drops its contents and a normal chest, which will not generate another kit when placed. Joining an existing chest preserves that chest's contents.

## Contents

| Equipment | Quantity and enchantments |
| --- | --- |
| Diamond armor | Full set, Protection IV and Unbreaking III; boots also have Feather Falling IV |
| Diamond sword | Sharpness V, Unbreaking III |
| Bow | Power V, Infinity, Unbreaking III |
| Diamond pickaxe | Efficiency IV, Unbreaking III |
| Shield | 1 |
| Arrows | 128; keep at least one in your inventory for Infinity |
| Steak / golden apples | 64 / 16 |
| Cobblestone | 192 |
| Water buckets | 2 |
| Ender Pearls / Eyes of Ender | 16 / 16 |
| Slow Falling potions | 3, four minutes each |
| Strength potion | 1, eight minutes |
| Splash Healing II potions | 2 |
| Torches / carved pumpkin | 64 / 1 |

Wear the armor and bring the bow, sword, pickaxe, food, blocks, water, and Slow Falling potions. Use Eyes of Ender to locate and activate a stronghold portal. Drink Slow Falling before the fight, shoot the exposed crystals, break the cages around protected crystals, and use the sword while the dragon is perched. The pumpkin is optional for avoiding accidental Enderman aggression, and replaces your helmet while worn.

This kit supplies equipment, not an automatic win or an End portal. It targets the vanilla Ender Dragon, not a custom Darkspawn boss.

Build artifact: `build/starter-verification/libs/darkspawn-2.0.0-alpha.1.jar`. Includes the griffin and bonfire prototypes. Replace the previous Darkspawn JAR in the test instance, on both clients and server.
